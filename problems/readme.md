# Celefun 工程测试（problems）

用 Celefun 语言本身实现的 10 道算法 / 工程题。语言本身已冻结，这里只写程序。

每个题一个 .celefun 文件，输入从 stdin 读，输出写 stdout。

- `p01_gcd_lcm.celefun`   GCD 与 LCM
- `p02_sort.celefun`      排序 / 去重 / 众数
- `p03_expr.celefun`      中缀表达式求值
- `p04_fib_big.celefun`   超大斐波那契（矩阵快速幂）
- `p05_dijkstra.celefun`  单源最短路
- `p06_mst.celefun`       最小生成树
- `p07_edit.celefun`      编辑距离
- `p08_json.celefun`      JSON 规范化
- `p09_vm.celefun`        栈式虚拟机
- `p10_lisp.celefun`      简易 Lisp 解释器

通用约定：读写用 `日记` / `望远镜`（`第十章日记;` / `第十章望远镜;` 导入）。
